# v0.1.0 — Source prerelease / 源码预发布

## 简体中文

首个源码预发布，面向 Apple Silicon MacBook。运行目标为 macOS 13+，构建需要 Xcode 26+ 和 XcodeGen；App 界面当前为中文。

- 独立控制合盖保活与屏幕常亮，支持两种模式协调和失败警告。
- 支持手动、1–24 小时倒计时、Codex / Claude Code / MiniMax Code 任务完成、图形应用退出和拔电后停止。
- 提供最低电量、过热保护、登录启动、会话心跳和异常退出恢复。
- 修复未批准的 helper 被误判为旧版本、反复撤销登记的问题；增加对应回归检查。
- 修复自动停止期间可重新开启、多实例覆盖屏幕保持、登录启动失败被误报成功的问题。
- 移除屏幕保活中已不使用的合盖检测代码，保留已有开关时序修复。
- 重写中英文 README，补齐操作说明、模式边界、升级授权与卸载步骤，移除过时截图。

本发行仅提供 GitHub 自动生成的源码归档，**不包含签名公证的 App / DMG**。构建安装方法见 [中文 README](../../README.md)。

自动回归、12 种界面状态、Release 构建与本地 DMG 打包用于验证源码和构建流程，不代表硬件验收完成。持续熄屏、全新机器首次授权、完整升级路径以及当前组合版本的物理合盖矩阵仍未确认；不保证覆盖 macOS 自身的合盖显示行为。Intel、Homebrew、自动更新与 Mac App Store 分发未提供验证或发行支持。

## English

The first source-only prerelease for Apple Silicon MacBooks. The deployment target is macOS 13+; building requires Xcode 26+ and XcodeGen. The application UI is currently Chinese.

- Independent lid keep-awake and screen-awake modes, with helper coordination and failure warnings.
- Manual stop, a 1–24 hour timer, Codex / Claude Code / MiniMax Code task completion, GUI app exit, and power adapter disconnection.
- Battery and thermal guards, launch at login, session heartbeats, and crash recovery.
- Fix repeated unregistration when an unapproved helper could not answer a version probe; add a regression check.
- Fix restart during automatic cleanup, cross-process display-hold interference, and false success when a login-item change fails.
- Remove unused lid detection from display assertions while preserving existing switch-ordering fixes.
- Rewrite Chinese and English READMEs with feature instructions, interaction limits, upgrade approval, and uninstall steps; remove outdated screenshots.

This release provides GitHub's source archives only, **not a Developer ID signed and notarized App / DMG**. See the [English README](../../README.en.md) to build and install.

Automated regressions, 12 menu states, a Release build, and local DMG packaging validate the source and build process, not hardware acceptance. Continuous display sleep, fresh-machine approval, the full upgrade path, and physical lid tests for this combined version remain unverified. The app does not guarantee overriding macOS lid-display behavior. Intel, Homebrew, automatic updates, and Mac App Store distribution are not validated or shipped.
